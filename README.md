# 🎮 FunGames

一个纯前端的 HTML5 小游戏合集：无构建步骤、无框架、无第三方依赖，只有 HTML / CSS / 原生 JavaScript，推到 GitHub Pages 就能玩。

**内置 6 款游戏，全部支持触屏 / 鼠标 / 键盘、本地存档、深浅色主题。**
其中最值得说的是**五子棋 AI** —— 它不是随机落子的假 AI，而是一台真正的极小化极大博弈树搜索引擎（带 α-β 剪枝、迭代加深与置换表），详见下方「⭐ 旗舰：五子棋 AI」一章。

## ⭐ 旗舰：五子棋 AI

25 路棋盘，玩家先手执黑，AI 执白，任意方向连成 5 子获胜。AI 引擎单独放在 [`js/games/gomoku-ai.js`](js/games/gomoku-ai.js)：纯逻辑、零 DOM、可独立在 Node 里跑测试。

### 算法一览

| 环节 | 实现 |
| --- | --- |
| **棋盘** | 一维 `Uint8Array(625)`，`index = row * 25 + col`；双方用 1 / 2 表示 |
| **评估函数** | 枚举全盘 **1932 个「连续 5 格」窗口**，按形状打分（活四 / 冲四 / 活三 / 眠三 / 活二 / 眠二），两侧分数相减 |
| **增量评估** | 落子只会影响包含该格的窗口（含以该格为**边界**的窗口），`applyMove` / `undoMove` 局部重算，避免每次全盘扫描 |
| **候选着法** | 只考虑已有棋子切比雪夫距离 2 以内的空位，把分支因子压下来 |
| **简单档** | 一步启发式：`进攻分(我下这里) + 防守分(对手下这里) × 0.9`，并且**会犯错** —— 25% 概率只看进攻、忽略对手威胁，正常行棋也只在前 3 名候选里按权重挑选 |
| **困难档** | Minimax（AI 最大化 / 对手最小化）+ **α-β 剪枝** + **迭代加深**（受时间预算约束）+ **置换表**（52 位双分量 Zobrist 哈希）+ 着法排序（轻量分筛 → 完整启发式分排序） |

### 形状分值表

```
count = 窗口内该方子的个数，open = 窗口两端开放的个数
─────────────────────────────────────────────
5 子           10,000,000   （连五，直接获胜）
4 子 + 2 开放   1,000,000   （活四，下一步必胜）
4 子 + 1 开放     100,000   （冲四）
3 子 + 2 开放     200,000   （活三）
3 子 + 1 开放       2,000   （眠三）
2 子 + 2 开放       2,000   （活二）
其余                    0   （窗口内混入对方子则整个窗口记 0）
```

窗口内只要有一颗对方子，整个窗口记 0 —— 这天然区分了「活」与「眠」，也能识别 `XX.XX` 这类断裂形状。

### 实测强度

用「搜索型棋手」（可指定层数，执黑先手）作为水平参照：

| 对手 | 对简单档 | 对困难档 |
| --- | --- | --- |
| 搜索 2 层 | 黑 **100%** 胜 | 黑 **0%** |
| 搜索 3 层 | 黑 **100%** 胜 | 黑 **0%** |
| 搜索 4 层 | 黑 **100%** 胜 | — |

- 简单档会输，而且输得像「新手」：漏堵活三、只看自己的进攻。
- 困难档目前对 2~3 层搜索保持全胜，实战思考时间平均约 **84ms / 手**（峰值约 220ms）。
- 一步制胜、封堵对手一步制胜、3 手内强制胜、双活三等战术用例全部通过。

### 几个值得记录的实现细节

- **边界窗口也算受影响**：落子不仅改变「包含该格」的窗口，还会改变「以该格为边界」的窗口的开放端数量。漏掉这一条会让增量评估和全盘重算对不上，进而影响每一步的选点。
- **置换表必须用非线性哈希**：最初用「加法 Zobrist」，它是线性的，不同局面之间会产生大量碰撞，搜索会被污染；改成两个 26 位异或哈希拼成 52 位键后才稳定。
- **深度不是越大越好**：实测深度 5 最强，深度 6 反而变弱 —— 因为评估函数在更深层的博弈树上产生了战略误判。所以默认 `maxDepth = 5`，思考预算 1500ms。下一步的提升方向是给评估加入**先手权 / 双威胁**建模，而不是继续加深。
- 试过「静态搜索（quiescence）」来消除视野盲区，实测反而降低强度且慢 10 倍，已回退。

### 井字棋 AI（附带一提）

[`js/games/tictactoe.js`](js/games/tictactoe.js) 里的 AI 用的是同一套思路的迷你版：**极小化极大 + α-β 剪枝**，同等最优着法之间随机挑选，避免每局走法一样。两档难度：

- **简单** = 搜 4 层 + 25% 概率故意走随机（会犯错，能赢）；
- **困难** = 完全搜索，三子连线里**不会输**（最多平局）。

### 数字华容道求解器

[`js/games/klotski-solver.js`](js/games/klotski-solver.js) 用 **IDA\*** 求最优解，启发函数是「曼哈顿距离 + 2 × 线性冲突」；大棋盘上最优解太深时会自动退化为**加权 IDA\***（次优但有效），再不行就给出单步贪心建议 —— 保证提示按钮永远有反馈。3×3 秒解、4×4 中位约 0.1s、5×5 最坏约 1s。

面板上有两种辅助：**💡 提示**只高亮下一步；**▶ 演示通关**会按解法逐格自动走完（每步 160ms，可随时点「⏹ 停止」中断，播放期间锁定手动输入）。**只要用过其中任何一种，这一局就不计入最高分**，结算里也会写明，避免纪录被辅助污染。

计时从**第一次移动**起表，精确到 0.1s。面板上有显式的 **⏸ 暂停 / ▶ 继续** 按钮（快捷键 `P`）：暂停会停表、锁住棋盘与操作并弹出遮罩；切走标签页或窗口失焦也会自动暂停，但**回来不会自己继续**，必须由玩家主动恢复。撤销不回退时间，防止靠撤销刷纪录。

### 其他亮点

- **断线续玩**：所有对局类游戏的棋盘状态都写入 `localStorage`，刷新页面接着玩；存档损坏会自动重开一局。
- **强制胜利检测**：扫雷首点必安全、五子棋 / 井字棋在落子后立即判五连 / 三连。
- **最高分机制**：纪录、实时徽章、破纪录提示由框架统一处理，游戏只需调两个方法（见文末开发者章节）。

## 🚀 本地预览

仓库自带的 [`.preview-server.js`](.preview-server.js) 是个零依赖静态服务器（只监听本机 `127.0.0.1:8787`）：

```bash
node .preview-server.js
# Preview server running at http://127.0.0.1:8787/
```

浏览器打开 <http://127.0.0.1:8787/> 即可。也可以 `npx serve .` 或 `php -S localhost:8000`；直接双击 `index.html` 也能跑，但部分浏览器在 `file://` 下会限制 `localStorage`。

## 🧩 框架与扩展（开发者向）

游戏本体之外的公共部分，主要方便继续加新游戏。

### 共享组件

**`FunGamesStorage`**（`js/storage.js`）—— 统一用它而不是直接操作 `localStorage`：

```js
FunGamesStorage.get('2048:best', 0)      // 读取（带默认值）
FunGamesStorage.set('2048:best', 2048)   // 写入（自动 JSON 序列化）
FunGamesStorage.remove('2048:state')
FunGamesStorage.isPersistent()           // storage 被禁用时返回 false
```

所有键自动加 `fungames:` 前缀；storage 不可用时静默降级到内存 Map，游戏不会中断。

**`FunGamesUI`**（`js/ui.js`）—— 共享页面框架：

```js
var page = FunGamesUI.createPage({
  title: '我的游戏',
  subtitle: '显示在标题下方的一句话',
  backHref: '../index.html',
  best: {
    storageKey: 'mygame:best',              // 也可以写成 () => 'mygame:best:' + diff
    label: '最高分数',
    format: function (v) { return v.toLocaleString('zh-CN'); },
    lowerIsBetter: false,                   // 计时类纪录改成 true
    recordMessage: '🎉 新的最高分！'         // 可选，自定义破纪录提示
  },
});

page.main.appendChild(/* 你的界面 */);
document.getElementById('app').appendChild(page.root);

page.onNewGame(reset);      // 标题栏的「新游戏」按钮
page.beginRun();            // 每局开始（含读取存档）时调用
page.setBest(score);        // 成绩变化时调用：实时刷新 + 破纪录提示
page.toast('已保存！');      // 临时提示

FunGamesUI.onSwipe(element, function (dir) { /* 'up'|'down'|'left'|'right' */ });
FunGamesUI.formatTime(75);  // -> "1:15"
```

`createPage()` 生成吸顶标题栏（返回链接、标题、最佳成绩徽章、「新游戏」按钮）。**纪录 + 实时显示 + 破纪录提示是框架内置能力**，游戏只要调 `page.beginRun()` 和 `page.setBest(value)` 就能获得；提示是底部 toast，不遮挡棋盘、每局只弹一次，`storageKey` 支持函数形式以便按难度分别记录。

### 加一个新游戏

1. 复制模板：`cp games/template.html games/snake.html`、`cp js/games/template.js js/games/snake.js`；
2. 按 `template.js` 里标注的 1–4 部分实现（页面框架 / 界面 / 存档 / 输入）；
3. 在 `js/manifest.js` 里注册一条（`id / title / description / icon / href / tags / best`），首页卡片自动出现；
4. 刷新验证：徽章显示「—」→ 实时变成绩 → 破纪录弹提示。

| 方面 | 建议 |
| --- | --- |
| 文件位置 | `games/<id>.html` + `js/games/<id>.js` |
| 存储键 | `<id>:best` 和 `<id>:state`（不要用裸名字） |
| 存档 | 每次有意义的变动都保存；启动时读取；数据不合法就重新开一局 |
| 输入 | 键盘和触屏都要支持；在游戏区域上正确设置 `touch-action` |
| 布局 | 挂在 `page.main` 里；棋盘宽度控制在 `min(100%, 440px)` 以内 |
| 样式 | 在 `css/style.css` 里加一个命名清晰的区块，并复用现有主题变量 |

## 🛠 常见问题

**改了代码要重新构建吗？**
不用，刷新浏览器即可。只有改了 `js/manifest.js` 才需要刷新首页。

**游戏数据存在哪里？**
浏览器本地的 `localStorage`，键名以 `fungames:` 开头；清除站点数据会一起清掉。

**为什么 `.preview-server.js` 是隐藏文件？**
它只是本地开发工具，GitHub Pages 直接托管静态文件、不会执行它，所以不影响部署。
